## キャラシ作成（蛍さんの卓のハウスルール要約）

- キャラシは蛍さんへ個別に1回提出する。
- 職業は原則ルールブック（2010・2015・2020も可）から選び、その内容に準じて作る。特徴表は採用しない。シナリオ指定・版権キャラ・KPに相談して合理性がある場合は一部変更可。
- 技能の上限は80（指定がある場合を除く）。職業ポイントは1ptから振ってよい。
- 初期値の任意ルール：目星・聞き耳は50、図書館は25＋EDU×1、英語はEDU×1（今回は現代扱い）。
- 興味ポイントを振った技能は、採用理由をメモに書く。
- 能力値は全体・一部どちらの振り直しも可、入れ替えは自由。EDUの最低値は6。
- 持ち物は書いていないと、立ち絵に含まれるものとその時代に持っていておかしくないものだけになる（後出し不可。シナリオ開始1時間前までなら相談可）。持ち込めるかはシナリオ次第。
- メモ欄はたくさん書いてよい（イメソンなども歓迎）。
- 詳しい作り方・ココフォリアの駒の置き方：蛍さんの初心者講座 https://sumptuous-sedum-4d5.notion.site/417f7bfe5a6e80d888f7d53d441c4379
